# Bank Analytics Dashboard (Power BI + MySQL) 

**Internship Project** – AI Variant (ExcelR Solutions) | Jul–Oct 2024  
Comprehensive banking analytics dashboard analyzing loan applications, customer demographics, funded amounts, interest rates, payment status, and credit risk.

## Business Impact
- Reduced loan defaults by **20%** through high-risk pattern identification  
- Improved loan approval & credit risk tracking by **15%**  
- Enabled data-driven decisions on customer prioritization and branch performance

## Key KPIs & Features
- Total Loan Applications: 39.7K | Total Funded: $445.6M | Total Received: $482.7M  
- Avg Interest Rate: 12.0% | Avg DTI: 13.3  
- Year-wise loan growth, Grade/Sub-grade revolver balance  
- Home ownership vs last payment, Verification status distribution  
- Interactive slicers: Purpose, Grade, Address State, Year

## Tech Stack
- Power BI Desktop (DAX, Power Query)  
- MySQL (data cleaning, joins, ETL)  
- File: `Bank_Analytics_Dashboard.pbix` (included – fully interactive)
